# Johnny HA native player

This source-only GPL-3.0-or-later port applies documented source hooks to Johnny Reborn by Jeremie Guillaume, upstream commit `524a5803e4fa65f840379c781f40ce39a927032e`. The build artifact includes upstream's full GPL license. SDL 2.30.11 is linked statically under its zlib license. Obtain complete corresponding source from this branch plus the pinned upstream and SDL release identified in the workflow. No Sierra artwork or original resource files are distributed here.

The Android View uses SDL software surfaces only: no SDL video backend, audio device, audio focus or audio routing is initialized. SDL Android backend dependencies are compiled for its internal JNI glue, but its Activity-binding JNI_OnLoad is renamed and never invoked; no SDLActivity is needed. Pixel artwork is drawn at its original 640x480 proportions with nearest-neighbor scaling. Existing preview/Dream/Now Playing wrappers own the View lifecycle. Place privately owned original RESOURCE.MAP and RESOURCE.001 in the app's files/johnny directory. The engine's private story-progress file also stays in that directory; neither process working directory nor environment variables change.

Java API: NativeJohnnyView(Context), start(), stop(), setNight(boolean), requestFan():boolean, getStatus():String. Stop is nonblocking and cancels the engine at its next interruptible tick/frame boundary; allocation ownership is unwound before another native generation starts. Detached Views stop. Call start after making the View visible. HA state deduplication belongs to the client; each accepted request queues one complete MISCGAG.ADS:1 routine (capacity 8). A queued fan now interrupts a normal ADS routine or walk at the next frame boundary, using normal thread/slot/saved-layer cleanup. It skips the approach walk and transition fade, then runs the original full fan routine to its natural end. Further genuine edges queue behind a currently playing fan without interrupting it; stable on-state does not create new requests. Stopping the screen cancels playback rather than completing a hidden routine.

Original story selection remains in use except MISCGAG.ADS:1, which is excluded from automatic selection and remains available only through explicit HA fan requests. Fan requests select the original fan descriptor and never rewrite DOS memory. HA night state overrides the old clock-derived island selection. Live night changes rebuild the island from original NIGHT.SCR/day ocean resources on the render thread, retaining running ADS/TTM state, saved scene image layer, island position, tide and raft state. Cloud placement can be reselected by upstream island initialization. Scenes that replace the entire background retain their original scripted art; HA night remains authoritative for the next island. No dark filter is used.

Hosted checks cover command queue bounds, cancellation policy, tick wraparound, frame buffer dimensions, Java compilation, and arm64 Android linking. They do not establish on-device visuals, fan timing, real day/night appearance or audio-route acceptance. Original resources remain private and are not used by hosted tests.

## OI reaction (version 10 candidate)

The private approved SHRUG.000 through SHRUG.004 PNGs and OI-BUBBLE.png are loaded from Android assets/oi without scaling; none are stored in this repository. The five poses are80x90 and the bubble92x64. Native bounds are fixed at41888ARGB pixels. Missing/invalid assets disable OI requests while retaining the original story.

NativeJohnnyView adds requestOi():boolean and cancelOi(). setNight(false) cancels automatically. The HA client owns confirmed light-edge detection; native requests coalesce rather than accumulate. A dedicated single-actor sequence follows ordinary ADS cleanup and stages the island at its canonical origin. It uses original SHKNFIST frame0 for the initial250ms, then the approved3.15s pose timeline at341,218, bubble284,160 and the reference black/white tail triangles. No smoothing or additional audio calls are used.

A full fan is never interrupted by OI. At most one OI waits behind it; a new fan can interrupt an unfinished OI and retain one pending restart while still night. Completed OI reactions are not requeued. Day/unknown cancellation invalidates the current reaction generation and clears pending work; a newer off edge survives the previous generation's cleanup. Native status reports oi=completed/started, oiPending and oiReady. Hosted tests use synthetic pixels only and do not establish device visual acceptance.
