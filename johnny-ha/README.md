# Johnny HA native player

This source-only GPL-3.0-or-later port applies documented source hooks to Johnny Reborn by Jeremie Guillaume, upstream commit `524a5803e4fa65f840379c781f40ce39a927032e`. The build artifact includes upstream's full GPL license. SDL 2.30.11 is linked statically under its zlib license. Obtain complete corresponding source from this branch plus the pinned upstream and SDL release identified in the workflow. No Sierra artwork or original resource files are distributed here.

The Android View uses SDL software surfaces only: no SDL video backend, audio device, audio focus or audio routing is initialized. SDL Android backend dependencies are compiled for its internal JNI glue, but its Activity-binding JNI_OnLoad is renamed and never invoked; no SDLActivity is needed. Pixel artwork is drawn at its original 640x480 proportions with nearest-neighbor scaling. Existing preview/Dream/Now Playing wrappers own the View lifecycle. Place privately owned original RESOURCE.MAP and RESOURCE.001 in the app's files/johnny directory. The engine's private story-progress file also stays in that directory; neither process working directory nor environment variables change.

Java API: NativeJohnnyView(Context), start(), stop(), setNight(boolean), requestFan():boolean, getStatus():String. Stop is nonblocking and cancels the engine at its next interruptible tick/frame boundary; allocation ownership is unwound before another native generation starts. Detached Views stop. Call start after making the View visible. HA state deduplication belongs to the client; each accepted request queues one complete MISCGAG.ADS:1 routine (capacity 8). It starts at the next safe story routine boundary, including the original walk to the required position, and runs to its natural end. Stopping the screen cancels playback rather than completing a hidden routine.

Original story selection remains in use except MISCGAG.ADS:1, which is excluded from automatic selection and remains available only through explicit HA fan requests. Fan requests select the original fan descriptor and never rewrite DOS memory. HA night state overrides the old clock-derived island selection. Live night changes rebuild the island from original NIGHT.SCR/day ocean resources on the render thread, retaining running ADS/TTM state, saved scene image layer, island position, tide and raft state. Cloud placement can be reselected by upstream island initialization. Scenes that replace the entire background retain their original scripted art; HA night remains authoritative for the next island. No dark filter is used.

Hosted checks cover command queue bounds, cancellation policy, tick wraparound, frame buffer dimensions, Java compilation, and arm64 Android linking. They do not establish on-device visuals, fan timing, real day/night appearance or audio-route acceptance. Original resources remain private and are not used by hosted tests.
