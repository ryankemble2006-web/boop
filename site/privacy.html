Privacy

Plain English, please.

This little website does not need an account, analytics package, advertising tracker or cookie banner because it does not install any of those things.

This website

The site itself is static HTML, CSS, JavaScript and images. It does not contain sign-in, forms, analytics, advertising scripts or third-party embedded content. Your web host may still keep normal server logs such as IP address, requested path, browser details and timestamps for security and operations. Those logs are controlled by the hosting provider, not by code on this page.

The BOOP prototypes

BOOP's current product direction is local-first. Home Assistant remains the local authority for exposed smart-home devices, rooms and automations. Basic home control is not supposed to depend on a cloud conversation service.

Voice, notification and conversation features can require Android permissions or configured services. The project deliberately keeps those permissions scoped to the feature that needs them and avoids inventing extra authority just because it would be convenient.

Natural voice work

BOOP is experimenting with an optional local natural-voice pack. The design downloads a pinned model package once, verifies it, stores it in app-private storage and can use it offline afterwards. Natural voice playback remains unresolved after physical hardware testing, while ordinary Android speech is usable, so the natural path is described as experimental rather than finished.

Physical privacy direction

Future BOOP hardware explores privacy controls that are physically obvious: shutters, covers and cues you can see or hear rather than a tiny software indicator buried three menus deep. Those are design directions, not promises about hardware currently for sale.
