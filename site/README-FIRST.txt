BOOP WEBSITE — ROOT-READY PACKAGE
=================================

This ZIP is deliberately boring to deploy.

1. Open your hosting document root (often public_html in cPanel/File Manager).
2. Remove or rename the Sitejet-generated homepage if you no longer want it.
3. Upload this ZIP to the document root.
4. Extract it THERE.
5. Confirm index.html is directly inside the document root, not inside another BOOP folder.
6. Visit your domain over HTTPS.

The package does not contain PHP, Node, WordPress, a database, analytics, fonts,
trackers, build tools or a CMS. It does not touch sibling folders such as /apk/.

Runtime files:
  index.html
  privacy.html
  404.html
  styles.css
  site.js
  .htaccess
  assets/

The BOOP eye and yellow-hand PNGs are exact protected source bytes. Do not run
those images through an optimiser, image editor or Sitejet compression pass.
