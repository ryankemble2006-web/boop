# Build BOOP Alpha 1 on GitHub

The repository contains a GitHub Actions workflow that builds the APK in the cloud.

1. Put the contents of this folder at the root of a GitHub repository.
2. Commit/push to `main` (or open **Actions → Build BOOP Alpha 1 APK → Run workflow**).
3. Open the completed workflow run.
4. Download the `BOOP-Alpha1-debug` artifact.
5. Inside the artifact ZIP is `app-debug.apk`.

No Home Assistant token or other secret is required for Alpha 1.
