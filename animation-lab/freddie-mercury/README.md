# Freddie Mercury animation lab

Isolated visual-animation experiment. This folder is deliberately separate from BOOP Wall, Shield, Launcher, signing, permissions, and production app code.

## Locked visual rule
The canonical BOOP character remains the exact headphones BOOP used across the apps: same eyes, headphone silhouette, proportions, and overall character appearance. The Queen/Freddie Easter egg changes only performance language and temporary props.

Approved Freddie-style easter-egg ingredients:
- same locked headphones BOOP
- floating yellow puppet hands, with five fingers each
- handheld microphone
- Freddie-inspired stage posture / performance energy
- transparent background
- no new face, body, moustache, costume body, or replacement character

## Layer / provenance note
The image-generation tool produced flattened PNG outputs only. No editable PSD/XCF/AI layer stack was created or exposed, so there are no genuine source layers to archive. Do not invent or reconstruct fake layers and call them originals. If editable layers are later needed, derive them explicitly from the approved flattened asset and mark them as reconstructed.

## Motion direction
When Queen is detected, BOOP should remain himself and shift into a Freddie-inspired performance pose: floating yellow five-finger hands, mic in one hand, expressive eye/posture change, then return to normal BOOP. This is an Easter egg, not a redesign.

No BOOP app code is changed by this animation-lab branch unless Ryan explicitly asks later.
