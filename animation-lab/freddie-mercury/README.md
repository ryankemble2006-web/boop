# Freddie Mercury animation lab

Isolated visual-animation experiment. This folder is deliberately separate from BOOP Wall, Shield, Launcher, signing, permissions, and production app code.

## Goal
Create a stylised animated performance study of Freddie Mercury for animation-design exploration.

## Working direction
- recognisable Freddie Mercury stage presence
- black background for clean silhouette/readability
- white vest / Live Aid-era visual language as the starting point
- exaggerated but tasteful puppet motion rather than photoreal video imitation
- animation-first: strong readable poses, head/shoulder rhythm, mic-hand accents, planted-foot swagger
- no changes to BOOP app code from this branch unless Ryan explicitly asks later

## First motion pass
1. Neutral stage pose.
2. Weight shift onto one leg.
3. Shoulder snap and head turn.
4. Mic-hand punch forward.
5. Chest lift / brief hold.
6. Return with a smaller overshoot so the loop breathes.

Keep the loop short and readable before adding facial detail or secondary motion.
